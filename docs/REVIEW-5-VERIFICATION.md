## 4. What the report missed

   WorkManager stop/cancel into `Result.failure()`. This nullifies the executor's deliberate
   per-item rethrow (`OrganizeExecutor.kt:112-113`) and breaks the codebase's own convention —
   `MetadataService.kt:143-144`, `OrganizeSession.kt:403-404`, and `AppUpdate.kt:159-160` all
   rethrow `CancellationException` explicitly. Minor, but real and evidenced. (Impact on
   WorkManager retry semantics is CODE-INFERRED.)

uses `findChildDir` whose default is `ignoreCase = true` — `StorageGateway.kt:23-27` — so there
is no case-sensitivity gap; the updater's redirect-host check reads the final URL after
